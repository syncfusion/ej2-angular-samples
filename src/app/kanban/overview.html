This sample demonstrates a comprehensive task management scenario built with the Kanban component. It combines multiple features, including customized card and column header templates, swimlane grouping, tooltips, and column toggling to create an interactive workflow management experience.

The board is populated using a predefined task collection bound through the dataSource property, where each task is mapped to a workflow stage by the columns configuration using the keyField property.

In this demo, cards are styled with a card template that shows the assignee, tags, and a summary, while each column header is rendered with a header template that includes a status icon. Tasks are grouped by Assignee in a swimlane row, with tooltips and column toggling support to enhance interaction.
