This sample demonstrates the virtualization capabilities of the Kanban component, enabling efficient rendering and smooth interaction when working with large volumes of workflow data.

The sample is configured using a programmatically generated task collection (from generateKanbanDataVirtualScrollData) bound to the dataSource property. Each task is grouped under its columns based on the Status field (keyField) across the To Do, In Progress, Code Review, and Done columns. Each card is rendered using a custom card template that shows the task summary, type icon, ID, story points, priority icon, and assignee avatar.

The Kanban board UI virtualization feature renders only the column cards that are visible within the viewport, without buffering the entire data source. To enable virtualization, set the enableVirtualization property to true. Tooltips are also enabled via the enableTooltip property so that the full card title and summary are visible on hover.

In this demo, a dataset of 600K items has been configured for the dataSource property. Despite the large dataset, the Kanban board efficiently handles the rendering and interaction, ensuring a smooth user experience. Users can seamlessly navigate and interact with the Kanban board, even with such a significant amount of data. The generated task fields include Id, Type, Priority, Status, Assignee, StoryPoints, Tags, and Title, which drive the columns, priority indicator, type icon, story-points badge, and assignee avatar rendered on each card.
