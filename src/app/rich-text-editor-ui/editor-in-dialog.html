This sample demonstrates how to render the Rich Text Editor UI component inside a Dialog component for composing messages or content.

The Rich Text Editor UI is integrated with the Syncfusion Dialog component to create a message composer. Click the "Open Editor" button to launch the dialog with the RTE.

  • Dialog — Centers itself within the .sample-container.
  • Rich Text Editor UI — Rendered inside the Dialog content.
  • Send — Reads the editor content, displays the message, clears the editor, and closes the dialog.
  • Cancel — Clears the editor and closes the dialog.
