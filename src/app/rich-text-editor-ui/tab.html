This sample demonstrates how to embed the Rich Text Editor UI inside one of the tabs of the Tab component. The Rich Text Editor is initialized in the Summary tab when it is first selected.

The Tab component is combined with the Rich Text Editor UI to provide a tabbed interface where the editor lives inside the Summary tab. The other tabs (Remedies, Notes) display plain text content.

  • Tab — Provides the tabbed layout via the [items] input. The first item is selected by default.
  • Rich Text Editor UI — Programmatically initialized inside the Summary tab on the selected event of the Tab, so the editor is created only when needed.
