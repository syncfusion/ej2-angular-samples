This sample demonstrates an email composer experience built with the Rich Text Editor UI. Recipients are picked using the MultiSelect component, a Subject field captures the email subject, and the editor provides a rich text area for composing the message. Slash Command support is enabled in the editor for quick formatting. Use the Send and Discard buttons to clear the composer and trigger a Toast notification.

The Rich Text Editor UI provides the formatting tools needed to compose an email body. The Slash Command feature is enabled so users can quickly apply formatting or insert content by typing "/" inside the editor.

  • MultiSelect (Box mode) — Used to select multiple recipients for the To and Cc fields. Custom templates render each recipient with their avatar, name, and email.
  • Subject — A simple text input bound to the component through Angular two-way binding ([(ngModel)]).
  • Rich Text Editor UI — Provides a rich text area for composing the email body, with full formatting tools and Slash Command support.
  • Toast — Displays a confirmation message when an email is sent or discarded.

Click Send to clear the composer and show a success notification, or Discard to clear the composer and show a discard notification.
