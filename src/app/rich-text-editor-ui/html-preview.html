HTML SOURCE

This sample demonstrates the HTML preview functionality of the Rich Text Editor UI. The editor is paired with a Splitter and a CodeMirror instance to show a live, two-way preview of the underlying HTML source. You can edit the content from either the WYSIWYG editor or the code view, and the changes are reflected in the other.

The Rich Text Editor UI is combined with a Splitter and CodeMirror to provide a bi-directional HTML editing experience:

  • Rich Text Editor UI — Provides a WYSIWYG editing surface with formatting tools. The change and actionComplete events push the current HTML into CodeMirror.
  • Splitter — Splits the view into two resizable panes so the editor and the code view can be displayed side by side. On small devices the orientation is automatically switched to Vertical.
  • CodeMirror — Renders the live HTML source. Editing the source updates the Rich Text Editor through its value property and dataBind.
  • Copy — Copies the current HTML source (from CodeMirror if available, otherwise directly from the editor) to the clipboard and shows a Toast notification.
