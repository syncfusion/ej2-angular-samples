Properties

This sample demonstrates the properties of the Rich Text Editor UI component.

The Rich Text Editor UI component demonstrates the following properties and APIs:

  • valueFormat - Set the content format (HTML or JSON). Choose from the dropdown to convert content format.
  • value - Get or set the editor's content programmatically. Updates when the value format changes.
  • enabled - Enable or disable the RTE component. Checked by default.
  • readOnly - Set the RTE component as read-only, preventing user input.
  • enableRtl - Enable right-to-left direction for the RTE component.
  • enablePersistence - Enable persistence for maintaining the state of the RTE component.
