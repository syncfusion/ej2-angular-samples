This sample demonstrates a chat interface built using the Angular Chat UI component and Rich Text Editor UI as the message composer.

The Chat UI component is rendered using Angular component integration and the Rich Text Editor UI is used as the message composer.

  • Chat UI is rendered declaratively using ejs-chatui.
  • Rich Text Editor UI is used inside the Angular footer template as the message composer.
  • Reply selects a message and attaches replyTo metadata when sending.
  • Slash Command is enabled in the editor.
