This sample demonstrates the Inline AI Assist component with built-in speech-to-text for meeting notes. Select text to run a command or use the mic to dictate prompts.

In this example, the Inline AI Assist component showcase the following features:

  • speechToTextSettings - Enable built-in speech-to-text voice input for inline prompt request
  • commandSettings - Predefined commands (summary, extract actions, decisions, risks, follow-up, executive) applied to the selected text.
  • relateTo - Position the assistant popup near the selected paragraph for contextual suggestions.
  • promptRequest - Handle prompt submission and insert formatted AI responses into the editable notes area.
  • responseSettings - Manage Accept to insert AI output and Discard to cancel the suggestion.
