AI-Powered Chart Creation and Editing

Generate chart code, create visual previews, and modify charts using natural language.

This sample demonstrates the Syncfusion Angular AI AssistView component as a Chart Assist solution. Use natural-language prompts to create, visualize, modify, export, and print charts. The assistant provides Angular TypeScript code, configuration changes, and interactive chart previews directly within the conversation.

The Chart Assist experience uses the Angular AI AssistView component to interpret natural-language prompts and return structured chart configurations. The registered chart-tool mounts an isolated Angular chart preview for each response and renders either the Angular Chart or Angular Accumulation Chart component, depending on the requested visualization.

  • The [promptSuggestions] property provides predefined prompts for trend, comparison, and proportion visualizations.
  • The chart-tool displays response-specific Cartesian and accumulation chart previews from the normalized ChartConfig response.
  • The code-tool displays complete standalone Angular TypeScript code or only the Angular sections changed by a modification request. Each response maintains its own selected code view.
  • The change-summary-tool lists the configuration changes applied to its corresponding chart response.
  • Chat history stores complete sessions. Selecting a session restores its responses and latest chart configuration without changing charts rendered by other sessions.
  • Each chart preview owns its chart instance, Export control, Print button, status text, and active theme.
  • The bannerTemplate customizes the initial AI AssistView banner using an Angular ng-template.
  • The (promptRequest) event handles chart creation, modification, code requests, and response processing. Export and Print actions operate on the chart preview where the controls are selected.

Injecting modules

The response-specific standalone Angular chart component imports ChartModule and AccumulationChartModule. The required Cartesian, accumulation, financial, interaction, annotation, data-label, error-bar, trendline, technical-indicator, and export services are registered in the component's providers array.

Chart previews bind the active Syncfusion chart theme directly and refresh when the sample theme changes. This supports light, dark, and high-contrast themes without overriding chart SVG text colors.
