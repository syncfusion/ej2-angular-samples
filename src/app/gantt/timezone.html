This sample demonstrates how the Angular Gantt Chart schedules project tasks using the UTC timezone, ensuring consistent date and time handling across global teams.

When a user sets any timezone, dates are converted based on the value set to the timezone property of the Gantt control.

Gantt component features are segregated into individual feature-wise modules. To use selection and toolbar support, inject the SelectionService and ToolbarService into the @NgModule.providers section.

More information on the Essential® Angular Gantt Chart can be found in this documentation section.
