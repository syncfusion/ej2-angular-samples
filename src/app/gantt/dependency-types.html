The Gantt Chart supports dependency types to define relationships between tasks or features, helping control execution order and project sequencing.

The Gantt chart supports various dependency relationship types to manage task links. The allowedDependencyTypes property restricts the dependency types available during task editing and dependency creation.

The different types of dependency are:

  • FS - Finish to Start
  • SS - Start to Start
  • FF - Finish to Finish
  • SF - Start to Finish

When the dependency type list is configured, the Gantt validates newly created or modified links against the selected relationship types.

To use editing, toolbar, selection and MultiSelect checkbox functionality, inject the corresponding services in the providers section.
