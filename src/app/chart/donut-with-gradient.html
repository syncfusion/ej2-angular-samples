This example demonstrates a donut chart with radial gradient fills applied to each slice. The chart visualizes the share of e-commerce orders by country in 2025, with data labels displaying exact percentages and a legend showing country names with their respective shares. The radial gradient creates a three-dimensional visual effect that enhances the appearance of each slice.

In this example, each donut slice uses a radial gradient applied in the component's pointRender event using the radialGradient property. The gradient is defined with multiple color stops at different offsets, with brightness adjustments to create depth and a three-dimensional appearance. Each slice gets a unique base color from a predefined palette, and the gradient transitions from lighter to darker shades of that color.

Data labels are positioned outside the chart with connector lines, showing the exact percentage for each country. The legend also displays the full country name along with its percentage share.

Chart component features are segregated into individual feature-wise modules. To use pie series feature, we need to inject PieService into the @NgModule.providers section.

More information about the donut series can be found in this documentation section.
