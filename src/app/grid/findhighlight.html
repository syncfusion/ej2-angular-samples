This sample demonstrates the Grid find and highlight feature. Click Find in the toolbar and enter a value to highlight matching text in the Grid.

The Grid provides a find option to search its content and highlight matching text. In this demo, use the find method with the toolbar Find option to locate records and highlight the matching values.

More information on the searching configuration can be found in this documentation section.
